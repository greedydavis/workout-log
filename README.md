# 訓練紀錄

個人用的重訓與飲食紀錄 PWA。單一 HTML 檔，無外部依賴，資料存在瀏覽器 localStorage。

## 設計重點

- **輸入要快**：點動作即自動帶入上次的重量與次數，只改要改的地方。「＋ 再一組」複製上一組。
- **運動結構化、飲食不結構化**：重訓記到組數／重量／次數以便算趨勢；飲食純文字，不算熱量。
- **核心動作分層**：自由訓練會讓每個動作的紀錄很稀疏，所以只有釘選的 3～5 個動作畫進步曲線，其餘只保留「上次做多少」。
- **離線可用**：Service Worker 網路優先、失敗用快取，健身房沒訊號也能記錄。

## 頁面

| 分頁 | 內容 |
|---|---|
| 記錄 | 動作搜尋、今日紀錄、最近做過、飲食、體重 |
| 週 | 七天格子、訓練天數／總量／對比上週、本週動作彙總 |
| 趨勢 | 釘選動作的估算 1RM 曲線、體重曲線、釘選管理 |
| 設定 | 匯出／匯入 JSON、資料統計、清除資料 |

估算 1RM 用 Epley 公式 `1RM ≈ 重量 × (1 + 次數 / 30)`，讓不同重量與次數的組能放在同一個尺度上比較。次數超過約 12 下會高估，當趨勢看即可。

## 檔案


## 備份

資料只存在裝置的瀏覽器裡，清除瀏覽資料就會消失。請定期用「設定 → 匯出 JSON」保存；超過 14 天沒匯出時設定頁會提醒。
